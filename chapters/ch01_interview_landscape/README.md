# Chapter 01 — The Interview Landscape: exercises

Chapter 1 is orientation, not a pattern chapter, so these exercises turn its decisions into
small, deterministic, standard-library tools: which track to study, how to split prep time
across the rounds in your loop, what to check for each round format, whether the AI policy for a
round is actually verified, and how a rubric turns signals into a decision. Each one is also
ordinary interview practice (rule tables, grouping, proportional allocation, Counter scoring).

| ID | Title | Tier | Pattern / section | Target |
|---|---|---|---|---|
| [ex01](solutions/ex01_track_recommender.py) | Track recommender (S / M / L) | ★ Core | rule table, set intersection (§1.7) | 20 min |
| [ex02](solutions/ex02_loop_planner.py) | Interview-loop prep-hours planner | ★ Core | largest-remainder allocation (§1.1, §1.7) | 25 min |
| [ex03](solutions/ex03_round_checklist.py) | Round-format checklist generator | ★ Core | ordered de-duplication (§1.2, §1.3) | 20 min |
| [ex04](solutions/ex04_ai_policy_checker.py) | AI-policy evidence checker | ★ Core | group-by + rules over dated records (§1.4) | 30 min |
| [ex05](solutions/ex05_signal_scorer.py) | Interview signal scorer | ★ Core | weighted average + veto (§1.6) | 25 min |
| [ex06](solutions/ex06_study_plan_builder.py) | Study-plan builder | ★ Core | decision table + templating (§1.7) | 25 min |
| [ex07](solutions/ex07_job_description_classifier.py) | Job-description classifier | ◆ Extended | Counter over unigrams + bigrams (§1.5) | 25 min |

Each exercise has four files: `exercises/` (stub with hints), `solutions/` (reference),
`tests/` (pytest) and `outputs/` (generated by `tools/run_all.py`; never edit by hand).
All rubric weights, round weights and keyword lists are illustrative, not any company's real
values.

## How to run

```bash
# run one reference solution
.venv/Scripts/python chapters/ch01_interview_landscape/solutions/ex04_ai_policy_checker.py

# test the reference solutions
.venv/Scripts/python -m pytest chapters/ch01_interview_landscape

# test YOUR work in exercises/ (Git Bash)
TARGET=exercises .venv/Scripts/python -m pytest chapters/ch01_interview_landscape

# regenerate outputs/
.venv/Scripts/python tools/run_all.py --chapter 01
```

Suggested order: ex01 and ex06 first (pick your track and plan), then ex04 before you email a
recruiter, then the rest.
