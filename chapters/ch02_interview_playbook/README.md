# Chapter 02 — Interview Playbook (Short Form): exercises

These exercises practise the *method*, not a data structure: each one turns a step of the
6-step routine (clarify → examples → brute force → optimise → code → test) into a small,
deterministic, standard-library tool you can reuse on every later chapter.

| ID | Title | Tier | Pattern / method step | Target |
|---|---|---|---|---|
| [ex01](solutions/ex01_clarify_checklist.py) | Clarifying-question checklist builder | ◆ Extended | clarify (§2.2) | 20 min |
| [ex02](solutions/ex02_edge_case_generator.py) | Edge-case generator for a signature | ★ Core | examples & testing (§2.1, §2.6) | 20 min |
| [ex03](solutions/ex03_complexity_budget.py) | Complexity budget and doubling check | ★ Core | state complexity (§2.4) | 20 min |
| [ex04](solutions/ex04_dry_run_tracer.py) | Dry-run tracer (`sys.settrace`) | ◆ Extended | dry runs (§2.6) | 25 min |
| [ex05](solutions/ex05_stress_tester.py) | Self-test harness: brute vs optimised + shrinking | ★ Core | optimise, then test (§2.1, §2.5, §2.8) | 25 min |
| [ex06](solutions/ex06_timebox_planner.py) | Timebox planner for 45/60-minute rounds | ○ Reference | time management (§2.7) | 15 min |

Each exercise has four files: `exercises/` (stub with hints), `solutions/` (reference),
`tests/` (pytest) and `outputs/` (generated by `tools/run_all.py`; never edit by hand).

## How to run

```bash
# run one reference solution
.venv/Scripts/python chapters/ch02_interview_playbook/solutions/ex05_stress_tester.py

# test the reference solutions
.venv/Scripts/python -m pytest chapters/ch02_interview_playbook

# test YOUR work in exercises/ (Git Bash)
TARGET=exercises .venv/Scripts/python -m pytest chapters/ch02_interview_playbook

# regenerate outputs/
.venv/Scripts/python tools/run_all.py --chapter 02
```

Suggested order: ex05 first (it is the chapter's worked example), then ex02 and ex03, then the rest.
