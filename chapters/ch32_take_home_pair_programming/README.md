# Chapter 32 — Take-Home and Pair-Programming Workflow: exercises

These exercises practise the *workflow* of take-home and pair-programming rounds: scoping a
time box, structuring a small submission, checking it before you send it, finding your way
around unfamiliar code, refactoring behind characterization tests, and absorbing spec changes
one version at a time. Standard library only; every output is deterministic.

| ID | Title | Tier | Pattern | Section | Target |
|---|---|---|---|---|---|
| [ex01](solutions/ex01_expense_report_cli.py) | Sample take-home: expense summary CLI | ★ Core | parse → validate → compute → render → CLI | §32.2, §32.7 | 90 min |
| [ex02](solutions/ex02_submission_checker.py) | Pre-submission checker (README, tests, annotations, leftovers) | ◆ Extended | static checks with `ast` | §32.3 | 40 min |
| [ex03](solutions/ex03_code_navigator.py) | Navigate an unfamiliar codebase: definitions and call sites | ◆ Extended | `ast.NodeVisitor` index | §32.4 | 35 min |
| [ex04](solutions/ex04_refactor_characterization.py) | Refactor legacy code behind characterization tests | ★ Core | golden master → refactor → compare | §32.5 | 40 min |
| [ex05](solutions/ex05_checkout_kata.py) | Pair-programming kata: checkout v1 → v2 → v3 | ★ Core | incremental requirements, rules as data | §32.5, §32.6 | 45 min |
| [ex06](solutions/ex06_scope_planner.py) | Take-home scope planner (must/should/could) | ○ Reference | prioritising under a time box | §32.1 | 20 min |

Each exercise has four files: `exercises/` (stub with hints), `solutions/` (reference),
`tests/` (pytest) and `outputs/` (generated by `tools/run_all.py`; never edit by hand).
`data/transactions.csv` is the deliberately messy input for ex01.

## How to run

```bash
# run one reference solution
.venv/Scripts/python chapters/ch32_take_home_pair_programming/solutions/ex04_refactor_characterization.py

# test the reference solutions
.venv/Scripts/python -m pytest chapters/ch32_take_home_pair_programming

# test YOUR work in exercises/ (Git Bash)
TARGET=exercises .venv/Scripts/python -m pytest chapters/ch32_take_home_pair_programming

# regenerate outputs/
.venv/Scripts/python tools/run_all.py --chapter 32
```

Suggested order: ex06 (plan), ex01 (build), ex02 (check before you submit), then ex03 → ex04 →
ex05 as a pair-programming block.
