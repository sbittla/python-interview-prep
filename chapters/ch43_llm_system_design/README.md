# Chapter 43 — LLM System-Design Primer: exercises

These exercises turn the design-round habits of Chapter 43 into code you can run. You make
back-of-envelope estimates with stated assumptions (memory, latency, fleet size, cost),
simulate a gateway's routing and fallback, gate a release on an offline eval, and score your
own design notes. Standard library only. No network and no API keys. Every "model" is a
deterministic mock. **Every model, hardware, latency and price number is hypothetical**: the
numbers are round values chosen for practice, not descriptions of any real product.

| ID | Title | Tier | Pattern | Section | Target |
|---|---|---|---|---|---|
| [ex01](solutions/ex01_kv_memory_budget.py) | GPU memory budget: weights + KV cache (MHA vs GQA vs MQA) | ★ Core | estimate with stated assumptions | §43.1, §43.2 | 20 min |
| [ex02](solutions/ex02_latency_roofline.py) | Prefill vs decode latency with a roofline estimate | ★ Core | max(compute, memory) per phase | §43.2 | 30 min |
| [ex03](solutions/ex03_fleet_sizing_cost.py) | Fleet size and cost for a target QPS; self-host vs API break-even | ◆ Extended | per-phase pools, batch from the SLO | §43.2 | 35 min |
| [ex04](solutions/ex04_gateway_router.py) | LLM gateway: routing, fallback, deadlines, cache, metrics | ★ Core | ordered candidates + deadline propagation | §43.3, §43.5 | 40 min |
| [ex05](solutions/ex05_eval_gate.py) | Offline eval pipeline with a regression gate | ◆ Extended | golden set → slices → flips → gate | §43.4 | 40 min |
| [ex06](solutions/ex06_design_rubric.py) | Design-doc rubric scorer | ○ Reference | checklist as data, partial credit | §43.1, §43.6 | 20 min |

Each exercise has four files: `exercises/` (a stub with hints), `solutions/` (the reference
solution), `tests/` (pytest) and `outputs/` (generated by `tools/run_all.py`, so never edit
these by hand). ex03 repeats the small formulas from ex01 and ex02 as "given" code, so it
runs on its own.

## How to run

```bash
# run one reference solution
.venv/Scripts/python chapters/ch43_llm_system_design/solutions/ex03_fleet_sizing_cost.py

# test the reference solutions
.venv/Scripts/python -m pytest chapters/ch43_llm_system_design

# test YOUR work in exercises/ (Git Bash)
TARGET=exercises .venv/Scripts/python -m pytest chapters/ch43_llm_system_design

# regenerate outputs/
.venv/Scripts/python tools/run_all.py --chapter 43
```

Suggested order: ex01 → ex02 → ex03 (one estimate chain, as in the §43.2 walk-through), then
ex04 (gateway), ex05 (evals), and ex06 to check your notes after a mock design round.
