# Chapter 46 — AI-Assisted Round Practice: exercises

Every exercise ships a plausible but subtly wrong **"generated" function** as given code (no real
AI calls). You (a) write the tests or edge cases that expose it, often a seeded property check
against a brute-force oracle, (b) fix it, and (c) state its complexity. The tests check both
sides: the generated version **fails** your bug-finding tools and your fix **passes** them.
Standard library only; every output is deterministic.

| ID | Title | Tier | Bug / skill | Section | Target |
|---|---|---|---|---|---|
| [ex01](solutions/ex01_lower_bound_boundary.py) | Fix a generated binary search | ★ Core | wrong boundary; oracle + seeded random cases | §46.4 | 20 min |
| [ex02](solutions/ex02_dedupe_hidden_state.py) | Fix a generated dedupe | ★ Core | mutable default; hidden O(n²) `in list`, counted with probe objects | §46.4 | 20 min |
| [ex03](solutions/ex03_top_k_tie_breaking.py) | Fix a generated top-k words | ◆ Extended | tie-breaking, `split(" ")`, empty input; failures classified by kind | §46.4 | 25 min |
| [ex04](solutions/ex04_mean_price_rounding.py) | Fix a generated average | ◆ Extended | float + half-even rounding, empty list; exact `Fraction` oracle | §46.4 | 20 min |
| [ex05](solutions/ex05_review_optimise_window.py) | Review and optimise a generated sliding-window sum | ◆ Extended | review notes, off-by-one, O(nk) → O(n), element-read counting | §46.5 | 30 min |
| [ex06](solutions/ex06_tradeoff_checklist.py) | Explain the trade-offs: a checklist scorer | ◆ Extended | rubric as data, word-boundary regexes, a scored explanation | §46.6 | 25 min |

Each exercise has four files: `exercises/` (stub with hints; the generated code is given),
`solutions/` (reference), `tests/` (pytest) and `outputs/` (generated by `tools/run_all.py`;
never edit by hand).

## How to run

```bash
# run one reference solution
.venv/Scripts/python chapters/ch46_ai_assisted_practice/solutions/ex01_lower_bound_boundary.py

# test the reference solutions
.venv/Scripts/python -m pytest chapters/ch46_ai_assisted_practice

# test YOUR work in exercises/ (Git Bash)
TARGET=exercises .venv/Scripts/python -m pytest chapters/ch46_ai_assisted_practice

# regenerate outputs/
.venv/Scripts/python tools/run_all.py --chapter 46
```

Suggested order: ex01 → ex02 (the two core bug hunts), ex06 (explain the ex02 fix), then
ex03, ex04, ex05. Practise each one twice: once with an assistant writing the fix while you
write the tests, once AI-free (§46.7).
