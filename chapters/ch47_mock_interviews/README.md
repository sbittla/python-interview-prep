# Chapter 47 — Mock Interviews with Rubrics: exercises

This chapter is a toolkit for *running* mocks: a validated catalogue of the ten mocks
(`data/mocks.json`), the two rubrics from the outline, a log analyser, a progress tracker and a
peer-interviewer script. It contains no new interview problems. Every mock points at an existing
chapter exercise or a Chapter 45 bank problem, and `ex02` checks that each referenced file exists.

| ID | Title | Tier | Pattern | Target |
|---|---|---|---|---|
| [ex01](solutions/ex01_rubric_scorer.py) | Weighted rubric scorer with feedback | ★ Core | rubric as data + validation (§47.3, §47.4) | 25 min |
| [ex02](solutions/ex02_mock_planner.py) | Mock catalogue, time boxes, seeded rotation | ◆ Extended | validated catalogue + round-robin over shuffled queues (§47.2) | 30 min |
| [ex03](solutions/ex03_session_log_analyser.py) | Mock session log analyser | ★ Core | parse, validate, single-pass metrics (§47.1) | 30 min |
| [ex04](solutions/ex04_progress_tracker.py) | Progress tracker: trend, weakest criteria, study plan | ◆ Extended | least squares + ranked deficits (§47.5) | 30 min |
| [ex05](solutions/ex05_peer_script.py) | Peer-interviewer script generator | ○ Reference | template filled from validated data (§47.1) | 20 min |

Data:

- `data/mocks.json`: the ten mocks (4 SWE, 3 Data/ML, 3 GenAI/LLM), with time splits, problem
  references and repo paths, read-aloud prompts, graded hints, "strong looks like" and follow-ups.
- `data/logs/*.log`: three scripted session logs (`MM:SS EVENT [detail]`).
- `data/scores.csv`: a scored history of eight mocks for the tracker.

Each exercise has four files: `exercises/` (stub with hints), `solutions/` (reference),
`tests/` (pytest) and `outputs/` (generated by `tools/run_all.py`; never edit by hand).
`ex04` and `ex05` import `ex01` (and `ex05` imports `ex02`) from the same folder, so do them in order.

## How to run

```bash
# one reference solution
.venv/Scripts/python chapters/ch47_mock_interviews/solutions/ex05_peer_script.py

# test the reference solutions
.venv/Scripts/python -m pytest chapters/ch47_mock_interviews

# test YOUR work in exercises/ (Git Bash)
TARGET=exercises .venv/Scripts/python -m pytest chapters/ch47_mock_interviews

# regenerate outputs/
.venv/Scripts/python tools/run_all.py --chapter 47
```

Suggested order: ex01, then ex03 (log your own mock and analyse it), ex02, ex04, ex05.
